# Tin Tức (News) Management Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a full news/blog management system at `/manager/articles` (manager full CRUD), `/vice-manager/articles` (view only), and a public `/tin-tuc` page with paginated articles and modern card-grid design.

**Architecture:** Three database tables (article_categories, tags, articles) plus one pivot (article_tag). Manager controllers follow the same namespace and route patterns as the existing `LearningMaterialController`. The public page reuses the existing home layout and Alpine.js / Tailwind stack. Rich text editing uses Quill.js via CDN — no build step needed.

**Tech Stack:** Laravel 11, Blade, Alpine.js 3.x (CDN), Tailwind CSS (CDN), Quill.js 2.x (CDN), Material Symbols Outlined icons, `x-app-layout` component.

```php
<?php
namespace App\Models;

use Illuminate\Database\Eloquent\Builder;
use Illuminate\Database\Eloquent\Model;
use Illuminate\Database\Eloquent\Relations\BelongsTo;
use Illuminate\Database\Eloquent\Relations\BelongsToMany;

class Article extends Model
{
    protected $fillable = [
        'title', 'slug', 'thumbnail', 'excerpt', 'content',
        'status', 'article_category_id', 'author_id', 'published_at',
    ];

    protected $casts = [
        'published_at' => 'datetime',
    ];

    public function category(): BelongsTo
    {
        return $this->belongsTo(ArticleCategory::class, 'article_category_id');
    }

    public function author(): BelongsTo
    {
        return $this->belongsTo(User::class, 'author_id');
    }

    public function tags(): BelongsToMany
    {
        return $this->belongsToMany(Tag::class);
    }

    public function scopePublished(Builder $query): Builder
    {
        return $query->where('status', 'published');
    }
}
```

<?php
namespace App\Http\Controllers\Manager;

use App\Http\Controllers\Controller;
use App\Models\ArticleCategory;
use Illuminate\Http\RedirectResponse;
use Illuminate\Http\Request;
use Illuminate\Support\Str;
use Illuminate\View\View;

class ArticleCategoryController extends Controller
{
    public function index(): View
    {
        $categories = ArticleCategory::with('parent')->orderBy('sort_order')->orderBy('name')->get();
        return view('manager.article-categories.index', compact('categories'));
    }

    public function create(): View
    {
        $parents = ArticleCategory::orderBy('sort_order')->orderBy('name')->get();
        return view('manager.article-categories.create', compact('parents'));
    }

    public function store(Request $request): RedirectResponse
    {
        $data = $request->validate([
            'name'       => ['required', 'string', 'max:100'],
            'parent_id'  => ['nullable', 'exists:article_categories,id'],
            'sort_order' => ['nullable', 'integer', 'min:0'],
        ]);

        $data['slug'] = Str::slug($data['name']);
        $data['sort_order'] = $data['sort_order'] ?? 0;

        ArticleCategory::create($data);

        return redirect()->route('manager.article-categories.index')
            ->with('success', 'Category created successfully.');
    }

    public function edit(ArticleCategory $articleCategory): View
    {
        $parents = ArticleCategory::where('id', '!=', $articleCategory->id)
            ->orderBy('sort_order')->orderBy('name')->get();
        return view('manager.article-categories.edit', compact('articleCategory', 'parents'));
    }

    public function update(Request $request, ArticleCategory $articleCategory): RedirectResponse
    {
        $data = $request->validate([
            'name'       => ['required', 'string', 'max:100'],
            'parent_id'  => ['nullable', 'exists:article_categories,id'],
            'sort_order' => ['nullable', 'integer', 'min:0'],
        ]);

        $data['slug'] = Str::slug($data['name']);
        $data['sort_order'] = $data['sort_order'] ?? 0;

        $articleCategory->update($data);

        return redirect()->route('manager.article-categories.index')
            ->with('success', 'Category updated successfully.');
    }

    public function destroy(ArticleCategory $articleCategory): RedirectResponse
    {
        $articleCategory->delete();

        return redirect()->route('manager.article-categories.index')
            ->with('success', 'Category deleted successfully.');
    }
}

<?php
namespace App\Http\Controllers\Manager;

use App\Models\Tag;
use Illuminate\Http\RedirectResponse;
use Illuminate\Http\Request;
use Illuminate\Support\Str;
use Illuminate\View\View;

class TagController extends Controller
{
    public function index(): View
    {
        $tags = Tag::withCount('articles')->orderBy('name')->get();
        return view('manager.tags.index', compact('tags'));
    }

    public function create(): View
    {
        return view('manager.tags.create');
    }

    public function store(Request $request): RedirectResponse
    {
        $data = $request->validate([
            'name' => ['required', 'string', 'max:80', 'unique:tags,name'],
        ]);

        $data['slug'] = Str::slug($data['name']);

        Tag::create($data);

        return redirect()->route('manager.tags.index')
            ->with('success', 'Tag created successfully.');
    }

    public function edit(Tag $tag): View
    {
        return view('manager.tags.edit', compact('tag'));
    }

    public function update(Request $request, Tag $tag): RedirectResponse
    {
        $data = $request->validate([
            'name' => ['required', 'string', 'max:80', 'unique:tags,name,' . $tag->id],
        ]);

        $data['slug'] = Str::slug($data['name']);
        $tag->update($data);

        return redirect()->route('manager.tags.index')
            ->with('success', 'Tag updated successfully.');
    }

    public function destroy(Tag $tag): RedirectResponse
    {
        $tag->delete();

        return redirect()->route('manager.tags.index')
            ->with('success', 'Tag deleted successfully.');
    }
}

use Illuminate\Support\Str;
use Illuminate\View\View;

class ArticleController extends Controller
{
    public function index(Request $request): View
    {
        $query = Article::with('category', 'author', 'tags')->latest();

        if ($search = $request->input('search')) {
            $query->where('title', 'like', "%{$search}%");
        }

        if ($status = $request->input('status')) {
            $query->where('status', $status);
        }

        if ($categoryId = $request->input('category_id')) {
            $query->where('article_category_id', $categoryId);
        }

        $articles   = $query->paginate(10)->withQueryString();
        $categories = ArticleCategory::orderBy('sort_order')->orderBy('name')->get();

        return view('manager.articles.index', compact('articles', 'categories'));
    }

    public function create(): View
    {
        $categories = ArticleCategory::orderBy('sort_order')->orderBy('name')->get();
        $tags       = Tag::orderBy('name')->get();

        return view('manager.articles.create', compact('categories', 'tags'));
    }

    public function store(Request $request): RedirectResponse
    {
        $data = $request->validate([
            'title'               => ['required', 'string', 'max:255'],
            'excerpt'             => ['nullable', 'string', 'max:500'],
            'content'             => ['required', 'string'],
            'status'              => ['required', 'in:draft,published,archived'],
            'article_category_id' => ['nullable', 'exists:article_categories,id'],
            'tag_ids'             => ['nullable', 'array'],
            'tag_ids.*'           => ['exists:tags,id'],
            'thumbnail'           => ['nullable', 'image', 'max:2048'],
        ]);

        $slug = Str::slug($data['title']);
        $slug = $this->uniqueSlug($slug);

        $thumbnailPath = null;
        if ($request->hasFile('thumbnail')) {
            $thumbnailPath = $request->file('thumbnail')->store('article-thumbnails', 'public');
        }

        $article = Article::create([
            'title'               => $data['title'],
            'slug'                => $slug,
            'excerpt'             => $data['excerpt'] ?? null,
            'content'             => $data['content'],
            'status'              => $data['status'],
            'article_category_id' => $data['article_category_id'] ?? null,
            'author_id'           => auth()->id(),
            'thumbnail'           => $thumbnailPath,
            'published_at'        => $data['status'] === 'published' ? now() : null,
        ]);

        $article->tags()->sync($data['tag_ids'] ?? []);

        return redirect()->route('manager.articles.index')
            ->with('success', 'Article saved successfully.');
    }

    public function show(Article $article): View
    {
        $article->load('category', 'author', 'tags');
        return view('manager.articles.show', compact('article'));
    }

    public function edit(Article $article): View
    {
        $categories    = ArticleCategory::orderBy('sort_order')->orderBy('name')->get();
        $tags          = Tag::orderBy('name')->get();
        $assignedTagIds = $article->tags->pluck('id')->toArray();

        return view('manager.articles.edit', compact('article', 'categories', 'tags', 'assignedTagIds'));
    }

    public function update(Request $request, Article $article): RedirectResponse
    {
        $data = $request->validate([
            'title'               => ['required', 'string', 'max:255'],
            'excerpt'             => ['nullable', 'string', 'max:500'],
            'content'             => ['required', 'string'],
            'status'              => ['required', 'in:draft,published,archived'],
            'article_category_id' => ['nullable', 'exists:article_categories,id'],
            'tag_ids'             => ['nullable', 'array'],
            'tag_ids.*'           => ['exists:tags,id'],
            'thumbnail'           => ['nullable', 'image', 'max:2048'],
        ]);

        $updateData = [
            'title'               => $data['title'],
            'excerpt'             => $data['excerpt'] ?? null,
            'content'             => $data['content'],
            'status'              => $data['status'],
            'article_category_id' => $data['article_category_id'] ?? null,
        ];

        if ($request->hasFile('thumbnail')) {
            if ($article->thumbnail) {
                \Illuminate\Support\Facades\Storage::disk('public')->delete($article->thumbnail);
            }
            $updateData['thumbnail'] = $request->file('thumbnail')->store('article-thumbnails', 'public');
        }

        if ($data['status'] === 'published' && !$article->published_at) {
            $updateData['published_at'] = now();
        }

        $article->update($updateData);
        $article->tags()->sync($data['tag_ids'] ?? []);

        return redirect()->route('manager.articles.index')
            ->with('success', 'Article updated successfully.');
    }

    public function destroy(Article $article): RedirectResponse
    {
        if ($article->thumbnail) {
            \Illuminate\Support\Facades\Storage::disk('public')->delete($article->thumbnail);
        }
        $article->delete();

        return redirect()->route('manager.articles.index')
            ->with('success', 'Article deleted successfully.');
    }

    private function uniqueSlug(string $base): string
    {
        $slug = $base;
        $i    = 1;
        while (Article::where('slug', $slug)->exists()) {
            $slug = $base . '-' . $i++;
        }
        return $slug;
    }
}

use App\Models\Article;
use App\Models\ArticleCategory;

public function tinTuc(Request $request): View
{
    $query = Article::with('category', 'author', 'tags')
        ->published()
        ->latest('published_at');

    if ($categoryId = $request->input('category_id')) {

## Implementation Notes

**Quill content output:** Use `quill.getSemanticHTML()` (Quill 2.x method) to get clean HTML. Render in Blade with `{!! $article->content !!}`. Never sanitize with `strip_tags` on save — preserve formatting. XSS protection is handled at the controller boundary (only authenticated managers can save content).

**Thumbnail storage:** Uses `public` disk (`storage/app/public/article-thumbnails/`). Requires `php artisan storage:link` once. URL: `asset('storage/' . $article->thumbnail)`.

**Slug uniqueness:** The `uniqueSlug()` helper in ArticleController appends `-1`, `-2` etc. to avoid collisions when two articles have the same title.

**Status transitions:** When status is changed to `published` and `published_at` is null, set `published_at = now()`. This preserves the original publish date on re-publish.

**No article detail page (public):** The plan does not include a public `/tin-tuc/{slug}` detail page — the scope was paginated list only. Add separately if needed.
